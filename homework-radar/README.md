# Homework Radar

Homework Radar is a parent-facing MVP that turns school emails into a clean homework dashboard.

This prototype uses the assignment due dates extracted from Gmail and Google Classroom emails in this conversation. The next backend step is to replace the static `assignments` list in `app.js` with a Gmail search and extraction flow.

## MVP Features

- Assignment dashboard sorted by urgency
- Parent and student view modes
- Class filters
- Due-date timeline
- Overdue, due-today, and this-week counts
- Duplicate-reminder cleanup represented in the sample data

## Product Direction

Parents should not need to ask “Do you have homework?” every day. The app should quietly collect the signal from school email, show what matters, and send reminders only when there is actually something to act on.
